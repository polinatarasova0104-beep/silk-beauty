# Silk Beauty — Салон красоты

Веб-приложение для салона красоты с онлайн-записью на услуги.

## Технологии

- **Backend:** Python 3.12, FastAPI
- **База данных:** SQLite (для приложения), Microsoft SQL Server (ER-диаграмма)
- **Frontend:** HTML, CSS, JavaScript
- **Контейнеризация:** Docker
- **CI/CD:** GitHub Actions
- **Реестр образов:** GitHub Container Registry (GHCR)
